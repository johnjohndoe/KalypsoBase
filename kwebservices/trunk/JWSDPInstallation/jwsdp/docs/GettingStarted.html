Getting Started with JavaTM Web Services Developer Pack 2.0

Introduction

The JavaTM Web Services Developer Pack (Java WSDP) is a single download that contains the following key technologies you can use to simplify building of Web services using the Java 2 Platform:

  • JAX-WS Version 2.0 EA (Java API for XML Web Services)
  • JAX-WSA Version 1.0 EA (Java API for XML Web Services Addressing)
  • Fast Infoset Version 1.0.1
  • Sun Java Streaming XML Parser Version 1.0 EA
  • XML Digital Signature Version 1.0.1
  • XML and Web Services Security Version 2.0 EA2
  • JAXB Version 2.0 EA (Java Architecture for XML Binding)
  • JAXP Version 1.3.1_01 (Java API for XML Processing)
  • JAXR Version 1.0.8_01 EA (Java API for XML Registries)
  • JAX-RPC Version 1.1.3_01 EA (Java API for XML-based RPC)
  • SAAJ Version 1.3 EA (SOAP with Attachments API for Java)

Java WSDP v2.0 runs in the following Web containers:

  • Sun Java System Application Server Platform Edition 8.1 2005Q2 Update 2
  • Tomcat 5.0 for Java WSDP
  • Glassfish (JAX-WSA and an experimental version of JAX-WS are the only technologies that are integrated into this container)
  • No Web container

Select the container into which you integrated the Java WSDP 2.0 component technologies to see how to quickly deploy your own Web applications, try out tools that come with the Java WSDP, and see where to get the documentation that more completely explains how to use the technologies in the Java WSDP.

Community

The main developer community is the jwsdp community at Java.Net. Java.Net hosts a number of projects and communities related to the Java WSDP. Sites include the JWSDP community (mailing list), the JAX-WS project (mailing list), the JAX-RPC project (mailing list), and the JAXB project (mailing list). There are Java Technology Forums for the following technologies: JSP and JSTL, Java Servlet Technology, JavaServer Faces Technology. There are also forums for Java Technology and XML and Java Technologies for Web Services, but the Java.Net mailing lists are preferred.

Please send feedback on the Java Web Services Developer Pack to users@jwsdp.dev.java.net.
