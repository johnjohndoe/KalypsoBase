Getting Started with JavaTM Web Services Developer Pack 2.0 with No Web Container

If you installed Java WSDP 2.0 but selected the no Web container option, you can do the following:

  • Use the following technologies, which do not require a Web container:
    • JAXB
    • JAXP
    • JAXR
    • SAAJ
    • XML Digital Signature
  • Run one of the following integration scripts to integrate your Java WSDP 2.0 installation with one of the following Web containers:
    • <JWSDP_HOME>/jwsdp-shared/bin/jwsdponsjsas.sh (Solaris/Linux) or <JWSDP_HOME>/jwsdp-shared/bin/jwsdponsjsas.bat (Windows) to integrate with Sun Java System Application Server Platform Edition 8.1 2005Q2 Update 2
    • <JWSDP_HOME>jwsdp-shared/bin/jwsdpontomcat.sh (Solaris/Linux) or <JWSDP_HOME>jwsdp-shared/bin/jwsdpontomcat.bat (Windows) to integrate with the Tomcat 5.0 for Java WSDP Container
    • <JWSDP_HOME>/jwsdp-shared/bin/jwsdponsjsas9.sh (Solaris/Linux) or <JWSDP_HOME>/jwsdp-shared/bin/jwsdponsjsas9.bat (Windows) to integrate with Glassfish

Make sure that you read the Integration Notes before you run the integration scripts. These notes describe property settings that you must modify before you can run the scripts and, if you run the integration scripts, steps you must take before you uninstall the Java WSDP.

See the index page at <JWSDP_HOME>/docs/index.html for links to the API documentation, release notes, and reference documentation for the Java WSDP technologies.

Visit the Java WSDP News website for news about soon-to-be-released technologies, such as the version of the Java Web Services Tutorial that provides information about technologies specific to this version of the Java Web Services Developer Pack.

Community

The main developer community is the jwsdp community at Java.Net. Java.Net hosts a number of projects and communities related to the Java WSDP. Sites include the JWSDP community (mailing list), the JAX-WS project (mailing list), the JAX-RPC project (mailing list), and the JAXB project (mailing list). There are Java Technology Forums for the following technologies: JSP and JSTL, Java Servlet Technology, JavaServer Faces Technology. There are also forums for Java Technology and XML and Java Technologies for Web Services, but the Java.Net mailing lists are preferred.

Please send feedback on the Java Web Services Developer Pack to users@jwsdp.dev.java.net.
