Java TM Web Services Developer Pack 2.0

The Java Web Services Developer Pack (Java WSDP) is an all-in-one download containing key technologies to simplify building of Web services using the JavaTM 2 Platform. The technologies comprising the Java Web Services Developer Pack are:

  • FastInfoset
  • XML & Web Services Security
  • Java API for XML Web Services (JAX-WS)
  • Java Architecture for XML Binding (JAXB)
  • SOAP with Attachments API for Java (SAAJ)
  • Java API for XML Processing (JAXP)
  • Sun Java Streaming XML Parser
  • XML Digital Signature API
  • Java API for XML Registries (JAXR)
  • Java API for XML-based RPC (JAX-RPC)
